# Software Installation Request

## Purpose
Employees request approved software through the organisation's software catalogue.

## Procedure
1. Select the required application from the approved catalogue.
2. Provide a business justification.
3. Submit the request for approval.
4. Track the request using its request or ticket ID.
5. After approval, the authorised provisioning process can install the software.

## Prototype limitation
HelpPilot AI records software requests and simulates provisioning. It does not install software on the employee's computer.
