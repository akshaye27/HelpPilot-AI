# Multi-Factor Authentication Problems

## Symptoms
The employee cannot complete multi-factor authentication (MFA).

## Troubleshooting
1. Check that the device has the correct date and time.
2. Confirm that the employee is using the registered authentication method.
3. Check network connectivity and retry the sign-in.
4. Follow the organisation's approved MFA recovery process.
5. Escalate if the registered device is unavailable or authentication repeatedly fails.

## Security
Never request MFA codes or approve an authentication request on behalf of an employee.
