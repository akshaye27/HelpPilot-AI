# Password Reset and Account Lockout

## Symptoms
The employee's password has expired or the account is locked.

## Troubleshooting
1. Confirm the employee's identity using the organisation's approved verification process.
2. Use the approved password-reset portal if available.
3. For a locked account, follow the authorised account-unlock process.
4. Ask the employee to sign in again after the reset or unlock.
5. Escalate repeated failures to the identity or IT support team.

## Security
Never ask for passwords, password-reset codes, or MFA codes.
