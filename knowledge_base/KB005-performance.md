# Slow Computer and Performance Issues

## Symptoms
The computer responds slowly or applications take a long time to open.

## Troubleshooting
1. Save work and close unnecessary applications.
2. Restart the computer if permitted.
3. Check whether system updates or approved scans are running.
4. Record which applications are affected and when the issue occurs.
5. Contact IT support if the problem persists.

## Security
Do not disable security software or install unapproved optimisation tools.
